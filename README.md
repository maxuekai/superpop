# superpop

球球大作战网页版（Agar.io-like）。原生 ES modules + canvas 2D，**没有构建步骤**，浏览器直接加载源码。

## 玩法

吃食物长大 → 比你大 1.15 倍的球能吃掉你 → 被吃后弹结算界面，一键再来一局。

- **分裂**：长到约 256kg 后可切成两半（质量守恒），分开方向垂直于前进方向，靠拢后会自动合并
- **对手**：同屏 6~12 个 AI，会追击更小的球、逃离更大的球、觅食，也会互相吃
- **排行榜**：右上角实时排名，球顶显示昵称，开局可起名

## 运行

### 本机 / 手机

```bash
npm run dev
```

打开 <http://localhost:3000>。零依赖静态服务器，**不需要先 `npm install`**。

启动时会在终端打印局域网地址并生成 `qr.png`（生成二维码需要装了可选的 devDependency `qrcode`），手机连同一 Wi-Fi 扫码即可游玩。

### 联机（尚未接通）

```bash
npm install
npm run server
```

服务端目前只是旧代码的平移，进度见 [TODO.md](TODO.md)。

## 操作

| 设备 | 操作 |
| --- | --- |
| 手机 | 按住屏幕**任意位置**拖动（浮动摇杆，松手即停） |
| 电脑 | `WASD` / 方向键移动，`Space` 分裂 |

## 开发

| 命令 | 作用 |
| --- | --- |
| `npm test` | 语法检查 + 58 条玩法规则单测（吃/互吃/分裂/合并/AI 决策/输入） |
| `npm run sim` | AI 逃跑能力仿真：满舵猎手追击 20 轮，看存活时间与被逼墙比例 |
| `npm run sim:food` | 食物密度与成长仿真：密度、命中概率、玩家与 AI 的成长曲线对比 |

仿真脚本都带固定随机种子（结果可复现）并支持命令行覆盖参数，例如：

```bash
npm run sim -- --sweep          # 扫猎手半径：看大球到底能不能追上
npm run sim:food -- --divisor 44   # 临时试一个速度分母，不改代码
```

**所有可调数值集中在 [`src/config.js`](src/config.js)**，每个常量旁边都写了调它的理由。改速度/AI/食物参数前先跑对应仿真，改完跑 `npm test`。
