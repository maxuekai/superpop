# superpop

球球大作战网页版（Agar.io-like）。原生 ES modules + canvas 2D，**没有构建步骤**，浏览器直接加载源码。

当前状态：**单机与局域网联机都可玩**。单机是完整闭环（AI 对手 / 互吃 / 死亡重生 / 分裂 / 称王）；
联机为服务端权威架构（60Hz 世界模拟 + 20Hz 快照 + 本地移动预测），同一 Wi-Fi 扫码进房、上限 8 人，
有人称王全场结算、8 秒倒计时自动开新局。

## 玩法

吃食物长大 → 比你大 1.15 倍的球能吃掉你 → 被吃后弹结算界面。

- **分裂**：长到约 256kg 后可切成两半（质量守恒），分开方向垂直于前进方向，靠拢后自动合并；边移动边分裂也没问题
- **称王**：质量到 30000kg 且全场第一即称王——单机直接结算本局；联机全场结算、倒计时自动开新局（一局定胜负的节奏）
- **对手**：同屏 6~12 个 AI（随体型增长），会追击更小的球、逃离更大的球（多方向打分不贴墙）、觅食，也会互相吃；联机真人不足时由 AI 自动补位
- **食物**：成簇生成、同簇同色；被吃光的区域会自动重新播种，不会出现"食物荒漠"
- **排行榜**：右上角实时排名，球顶显示昵称，开局可起名

## 运行

### 单机 / 开发预览

```bash
npm run dev
```

打开 <http://localhost:3000>。零依赖静态服务器，**不需要先 `npm install`**。
启动会打印局域网地址、生成并自动打开 `qr.png` 二维码（需要可选的 devDependency `qrcode`），手机同 Wi-Fi 扫码即玩。

### 联机（局域网多人）

```bash
npm install
npm run server
```

同一端口同时托管页面与 WebSocket，启动同样打印局域网地址并自动弹出二维码。手机扫码后选「联机」进房。

- 服务端权威：世界只在服务端跑（与单机同一份玩法代码），客户端只上行输入、收快照渲染；
  自己的球走本地预测，操作零延迟感
- 与 `npm run dev` 同抢 3000 端口，二选一跑；首次开服记得在 Windows 防火墙放行 node
- 环境坑（防火墙 / 端口占用 / git 代理）见 [docs/node-env.md](docs/node-env.md)

## 操作

| 设备 | 操作 |
| --- | --- |
| 手机 | 按住屏幕**任意位置**拖动（浮动摇杆，松手即停）；**双指捏合**缩放视野 |
| 电脑 | `WASD` / 方向键移动，`Space` 或右下按钮分裂，**滚轮或 `+`/`-`** 缩放视野 |
| 通用 | 左下角「菜单」结束本局回到开局界面；视野缩放不影响"球越大看得越远"的自动逻辑 |

## 开发

| 命令 | 作用 |
| --- | --- |
| `npm test` | 语法 + 结构性检查 + 115 条玩法规则单测 |
| `npm run verify` | **改动任何玩法数值后的唯一入口**：上面全部 + 11 条 config 不变量 + 追击/觅食两个仿真 |
| `npm run sim` | AI 逃跑能力仿真：满舵猎手追击 20 轮，看存活时间与被逼墙比例 |
| `npm run sim:food` | 食物密度与成长仿真：密度、命中概率、玩家与 AI 的成长曲线对比 |

仿真脚本都带固定随机种子（结果可复现）并支持命令行覆盖参数，例如：

```bash
npm run sim -- --sweep             # 扫猎手半径：看大球到底能不能追上
npm run sim:food -- --divisor 44   # 临时试一个速度分母，不改代码
```

**所有可调数值集中在 [`src/config.js`](src/config.js)**，每个常量旁边都写了调它的理由。
改玩法数值前先读 [docs/tuning.md](docs/tuning.md)（公式、实测数据与验收口径），改完跑
`npm run verify`——`npm test` 全绿发现不了手感类回归。
